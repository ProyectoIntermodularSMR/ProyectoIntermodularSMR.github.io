Ataque DDoS

Ataque de Denegación de Servicio Distribuido
ℹ️ Qué es

Un ataque DDoS (Distributed Denial of Service) tiene como objetivo principal saturar los recursos de un servidor, servicio web o red e imposibilitar el acceso a los usuarios legítimos. A diferencia de un ataque DoS convencional que proviene de una sola máquina, el DDoS aprovecha el poder de cientos o miles de dispositivos conectados a Internet distribuidos globalmente.

⚙️ Cómo funciona

El atacante infecta previamente miles de dispositivos mal protegidos (ordenadores, servidores o dispositivos IoT) mediante malware, creando una red de "equipos zombi" llamada Botnet. Cuando el atacante da la orden, toda la botnet envía simultáneamente un volumen masivo de peticiones ficticias (como inundaciones de paquetes SYN, peticiones HTTP GET o amplificación DNS) hacia la dirección IP del objetivo, consumiendo todo su ancho de banda o procesador hasta tumbarlo.

⚠️ Qué puede hacer

Interrupción total de páginas web corporativas y servicios de comercio electrónico, pérdidas financieras críticas por inactividad comercial, y agotamiento de recursos del equipo técnico. A menudo se utiliza también como una "cortina de humo" para distraer a los administradores mientras se ejecuta una intrusión de datos silenciosa en otra parte de la infraestructura.

🛡️ Cómo prevenirlo
  • Implementar servicios de mitigación perimetral basados en la nube de alta capacidad (como Cloudflare o AWS Shield) para absorber y filtrar el tráfico anómalo.
  • Configurar reglas estrictas de Rate Limiting (limitación de tasa de peticiones) en los servidores web para evitar el abuso desde IPs individuales.
  • Desplegar firewalls de aplicaciones web (WAF) que analicen el comportamiento de las peticiones HTTP/HTTPS entrantes y detecten patrones de botnets conocidas.
  • Utilizar balanceadores de carga eficientes para distribuir el tráfico legítimo entre múltiples servidores geográficamente dispersos.
  • Hardeneas las configuraciones de red bloqueando protocolos no utilizados a nivel perimetral y desactivando respuestas a pings masivos (ICMP).
🚨 Qué hacer si te attack
  • Activar inmediatamente los protocolos de mitigación de DDoS contratados con tu proveedor de infraestructura o hosting (mecanismos de limpieza de tráfico).
  • Analizar los registros (logs) del servidor web para identificar si el ataque está dirigido a la capa de red (Capas 3/4) o a la capa de aplicación (Capa 7).
  • Implementar reglas perimetrales temporales en el firewall para bloquear de golpe rangos geográficos de direcciones IP (Geo-blocking) si el ataque proviene de países fuera de tu mercado objetivo.
  • Desviar el tráfico hacia una infraestructura de "Sujeción de Red" (Scrubbing Centers) para separar los paquetes maliciosos del tráfico limpio de los usuarios reales.
